# MusicPlayer 贡献指南

## 如何贡献

### 1. 提交问题
- 在GitHub Issues中报告问题
- 提供详细的重现步骤
- 包括环境信息和日志

### 2. 开发流程
1. Fork仓库
2. 创建特性分支：
   ```bash
   git checkout -b feature/your-feature
   ```
3. 提交代码变更
4. 推送分支：
   ```bash
   git push origin feature/your-feature
   ```
5. 创建Pull Request

### 3. 代码规范
- 遵循现有代码风格
- 添加适当的单元测试
- 更新相关文档
- 保持提交信息清晰

### 4. 代码审查
- 所有PR需要至少一个核心成员批准
- 审查重点：
  - 代码质量
  - 功能完整性
  - 性能影响
  - 向后兼容性

### 5. 行为准则
- 遵守开源社区行为准则
- 保持专业和尊重的沟通
- 欢迎所有背景的贡献者
