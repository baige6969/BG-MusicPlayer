# MusicPlayer 用户指南

## 安装说明

### 系统要求
- Python 3.8+
- Windows/macOS/Linux

### 安装步骤
1. 克隆仓库：
   ```bash
   git clone https://github.com/your-repo/MusicPlayer.git
   ```
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

## 快速入门
1. 启动播放器：
   ```bash
   python main.py
   ```
2. 添加音乐文件夹：
   - 点击"添加文件夹"按钮
   - 选择包含音乐文件的目录

## 主要功能
### 1. 播放控制
- 播放/暂停
- 上一曲/下一曲
- 音量调节
- 播放模式切换

### 2. 播放列表管理
- 创建/删除播放列表
- 歌曲排序
- 搜索过滤

### 3. 元数据查看
- 自动显示歌曲信息
- 专辑封面显示
- 歌词查看

## 常见问题
Q: 为什么有些歌曲无法播放？
A: 请检查文件格式是否支持，目前支持MP3、FLAC、WAV等常见格式。

Q: 如何连接云音乐服务？
A: 在设置中输入您的账号信息即可。
